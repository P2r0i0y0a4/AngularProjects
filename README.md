## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* Angular CLI
* Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/P2r0i0y0a4/AngularProjects.git
```

2. Navigate to a project folder:

```bash
cd AngularProjects/Angular
```

3. Install dependencies:

```bash
npm install
```

4. Run the project:

```bash
ng serve
```

5. Open your browser and go to:

```
http://localhost:4200/
```
